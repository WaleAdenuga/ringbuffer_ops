now we have to do the same for head

however you have to know when the producer can claim a position vs when the slot is actually available

principles from spsc don't realy apply anymore:
head/tail
    ↓
logical reservation positions

seqno
    ↓
per-slot ownership/publication/reclamation

main thing is producer has to be based on seqno vs current_head
rather than head vs tail

difference = seqno - head

0       → producer owns/available position
< 0     → slot is still occupied → full
> 0     → another lifecycle state → retry


Same logic can be applied to reading


difference = seqno - (tail + 1)

0       → consumer owns/available position
< 0     → slot is probably empty
> 0     → another lifecycle state → retry
